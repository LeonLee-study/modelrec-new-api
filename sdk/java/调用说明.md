# 面部颜值分析 SDK 调用说明

面向 Java 调用方。传入访问令牌和图片，返回一份 Markdown 颜值分析报告。

- 坐标：`net.modelrec:face-report-sdk:1.0.0`
- 包名：`net.modelrec.sdk`
- 运行环境：Java 11 及以上
- 依赖：无第三方依赖

## 引入

在本仓库中安装到本地 Maven 仓库：

```bash
mvn -f sdk/java/pom.xml install
```

如果拿到的是已打包的 jar：

```bash
mvn install:install-file \
  -Dfile=face-report-sdk-1.0.0.jar \
  -DgroupId=net.modelrec \
  -DartifactId=face-report-sdk \
  -Dversion=1.0.0 \
  -Dpackaging=jar
```

在业务项目中声明依赖：

```xml
<dependency>
    <groupId>net.modelrec</groupId>
    <artifactId>face-report-sdk</artifactId>
    <version>1.0.0</version>
</dependency>
```

## 创建客户端

```java
FaceReportClient client = new FaceReportClient();
```

客户端可以复用，也可以在多个线程中同时调用。访问令牌不保存在客户端里，每次调用单独传入。服务地址已固定在 SDK 内部，创建客户端和调用时都不需要传入。

## 调用

一次调用需要两个参数：

| 参数 | 说明 |
| --- | --- |
| `apiKey` | 访问令牌，例如 `sk-...`。已经带 `Bearer ` 前缀时也可以直接传入 |
| `image` | 一张图片。可以是 `http://` 或 `https://` 地址，也可以是图片 Base64 |

```java
FaceReportClient client = new FaceReportClient();

String report = client.analyze(
        "sk-你的令牌",
        "https://example.com/photo.jpg",
        ImageType.URL);

System.out.println(report);
```

`analyze` 会等到报告生成结束后返回。返回值是完整报告文本，不会返回 `null`。

### 图片地址

`ImageType.URL` 只接受 `http://` 或 `https://` 开头的地址。

```java
String report = client.analyze(apiKey, "https://example.com/photo.jpg", ImageType.URL);
```

### 图片 Base64

`ImageType.BASE64` 接受下面两种写法：

- 纯 Base64 字符串
- `data:image/jpeg;base64,` 这种 data URL，`jpeg` 可换成实际图片类型

字符串中的空白会被去掉。标准 Base64 和 URL 安全 Base64（`+` `/` 与 `-` `_`）都可以。缺少末尾 `=` 时会自动补齐。

纯 Base64 会按文件头识别类型：

| 文件头 | 类型 |
| --- | --- |
| `/9j/` | JPEG |
| `iVBORw0KGgo` | PNG |
| `R0lGOD` | GIF |
| `UklGR` | WebP |
| 其他合法 Base64 | 按 JPEG 发送 |

```java
String report = client.analyze(apiKey, base64, ImageType.BASE64);

String reportFromDataUrl = client.analyze(
        apiKey,
        "data:image/png;base64," + base64,
        ImageType.BASE64);
```

### 自动判断图片类型

不传 `ImageType` 时：

- 以 `http://` 或 `https://` 开头：按图片地址处理
- 其他内容：按 Base64 处理

```java
String report = client.analyze(apiKey, "https://example.com/photo.jpg");
```

同一批图片既有地址又有 Base64 时，使用这个不带 `ImageType` 的方法。传入 `ImageType.URL` 或 `ImageType.BASE64` 后，这一批图片必须全部是同一种形式。

### 多张图片

用 `List<String>` 传入，顺序就是报告中的图1、图2。

```java
List<String> images = List.of(
        "https://example.com/front.jpg",
        "https://example.com/side.jpg");

String report = client.analyze(apiKey, images, ImageType.URL);
```

### 流式接收

增加 `FaceReportListener` 后，报告在生成过程中按文本片段回调。方法仍然会阻塞到结束，并返回拼接后的完整报告。回调线程就是发起调用的线程。片段按到达顺序直接拼接即可。

```java
String report = client.analyze(apiKey, imageUrl, ImageType.URL, delta -> {
    System.out.print(delta);
});
```

`listener` 传 `null` 时，只在方法返回时给出完整报告。

## 返回值

返回值是一份 Markdown 报告，包含综合评分、面部轮廓、皮肤状态、气质评分、市场价值和提升建议。多张图片时，每张图片各有一份报告。

## 异常

失败时抛出 `FaceReportException`，这是一个非受检异常。

- `getMessage()`：失败原因
- `getStatusCode()`：HTTP 状态码。参数错误、网络失败或还没有收到 HTTP 响应时为 `0`

```java
try {
    String report = client.analyze(apiKey, imageUrl, ImageType.URL);
} catch (FaceReportException ex) {
    int status = ex.getStatusCode();
    String reason = ex.getMessage();
}
```

常见情况：

| 情况 | `getMessage()` | `getStatusCode()` |
| --- | --- | --- |
| 令牌为空 | `apiKey 不能为空` | `0` |
| 图片为空，或图片列表为空 | `图片不能为空` | `0` |
| 声明为地址，但不是 `http://` 或 `https://` | `图片地址必须以 http:// 或 https:// 开头` | `0` |
| 声明为 Base64，但传入了图片地址 | `当前按 Base64 传入，不能是图片地址` | `0` |
| Base64 内容不合法 | `图片必须是 http(s) 地址，或图片 Base64` | `0` |
| Base64 长度不合法 | `图片 Base64 长度不合法` | `0` |
| data URL 不是 Base64 | `图片 data URL 必须是 Base64 格式` | `0` |
| 网络连接失败 | `请求失败` | `0` |
| 调用被中断 | `请求被中断` | `0` |
| 服务端返回 4xx 或 5xx | 服务端给出的错误说明；没有可用说明时为 `请求失败，HTTP <状态码>` | 对应 HTTP 状态码 |
| 响应内容无法读取 | `流式响应无法解析` 或 `请求失败` | `0` |

## 时间限制

- 建立连接：20 秒
- 单次调用从发起到返回：最长 5 分钟

超时按网络失败处理，抛出 `FaceReportException`，状态码为 `0`。
