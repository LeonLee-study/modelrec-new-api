## 前端数据需求（2026-10-16 最新）

> 此前 6 类（含分辨率/子类型/基座维度）已废弃；以下 10 类为准。

### F1. 抬头页配置项（前端写死，后端不返回）

| 配置项 | 值（小括号为动态值样例） | 说明 |
| --- | --- | --- |
| RECHARGE_RATE_CNY | ¥1 = (1,000) 燧点 | 人民币充值换算 |
| RECHARGE_RATE_USD | USD 1 = (7,000) 燧点 | 美元充值换算 |
| FIXED_FX | USD : CNY = 1 : (7) | 固定汇率，不随市场波动 |
| BENCHMARK_PRICE | USD 2 / 1M Token | 内部基准价，1 美元 = 50 万 Token 额度 |
| TOKEN_PER_SUIDIAN | 1 燧点 = (71.43) Token | 燧点与 Token 的换算锚点 |
| MULTIPLIER | (7,000) | 燧点价 = 官方原价（USD/1M）× 7000 |

后端另需返回：厂商数 / 模型数 count（实时，与模型广场一致）。

### F2. 筛选器模块

| 筛选项 | 说明 | 结论 |
| --- | --- | --- |
| 供应商分组 | 已有模型供应商集合 | 已有 vendors |
| 类别分组 | 文本对话 / 多模态理解 / 翻译 / 图像生成 / 视频生成 / 3D 资产 / … | 独立类别字段；按分类表；一级/二级跟广场配置一致 |

> 新版前端需求**不再要**「计费口径」筛选项。

### F3. 列表区域（按模型类型字段不同）

公共字段：模型展示名、类别、供应商。价格相关字段按类型区分；合表/同次返回，便于搜索筛选。

| 类型 | pricing_kind | 需要字段 |
| --- | --- | --- |
| 文本 | `text` | 展示名、类别、供应商、官方输入价 USD/1M、官方输出价 USD/1M、输入消耗燧点/1M、输出消耗燧点/1M |
| 多模态 | `multimodal` | 同上 |
| 图片生成 | `image_generate` | 展示名、类别、供应商、官方按张单价、燧点按张单价 |
| 图片识别 | `image_recognize` | 展示名、类别、供应商、官方按张单价、燧点按张单价 |
| 视频生成 | `video_generate` | 展示名、类别、供应商、官方按秒单价、燧点按秒单价 |
| 视频识别 | `video_recognize` | 展示名、类别、供应商、官方按秒单价、燧点按秒单价 |
| 语音合成 | `speech_synthesis` | 展示名、类别、供应商、官方按万字单价、燧点按万字单价 |
| 语音识别 | `speech_recognize` | 展示名、类别、供应商、官方按秒单价、燧点按秒单价 |
| 世界模型 | `world` | 展示名、类别、供应商、官方输入价（按次）、燧点输入价（按次）、官方输出价（按秒）、燧点输出价（按秒） |
| 向量与检索 | `vector` | 展示名、类别、供应商、官方文本输入价 USD/1M、燧点文本输入价/1M、官方向量输入价 USD/1M、燧点向量输入价/1M |

| 项 | 结论 |
| --- | --- |
| 模型输出范围 | 已确认：按筛选条件全量展示；无筛选时即模型广场全部模型（前端文案仍写「暂定需付总定」处，以产品已确认为准） |
| 官方价 | 从模型广场取数 |
| Token 类燧点价（USD/1M） | 后端按官方价 × 7000 算好返回 |
| 按张 / 按秒 / 按万字燧点价 | 同样由后端按官方单价 × 7000 算好返回（与 MULTIPLIER 一致） |

| 需求字段 | 适用类型 | 项目现状 | 结论 |
| --- | --- | --- | --- |
| 模型展示名 | 全部 | model_name | 已有；直接用 model_name，不另设字段 |

| 官方输入 / 输出价 USD/1M | 文本生成、多模态 | 现为内部倍率 | 从模型广场取数返回 |
| 输入 / 输出消耗燧点/1M | 文本生成、多模态 | 无 | 后端官方价 × 7000 |
| 官方单价 USD/1M、燧点单价/1M、维度 | 基座类 | 缺 | 官方单价取自广场；燧点 ×7000；需补维度字段 |
| 官方按张单价、燧点按张单价、分辨率 | 图片生成 | 部分有 model_price | 补齐；燧点后端 ×7000 |
| 官方按秒单价、燧点按秒单价、分辨率 | 视频生成 | 缺 / 部分 | 补齐；燧点后端 ×7000 |
| 官方按万字单价、燧点按万字单价、子类型 | 语言 | 缺 | 补齐；燧点后端 ×7000 |

| 项 | 结论 |
| --- | --- |
| 模型输出范围 | 按筛选条件全量展示；筛中的全部出；无筛选时即模型广场现有全部模型 |
| 列表数据形态 | 每条记录带厂商、类别、该类型对应价格字段，合表返回，便于搜索筛选 |

## 4. 汇总：后端后续要准备什么

| 优先级 | 项 | 说明 |
| --- | --- | --- |
| P0 | 厂商数、模型数 count | 接口直接返回；实时，与模型广场一致 |
| P0 | 独立类别字段 + 按分类表补录（含一级/二级） | 筛选器 + 列表；跟广场配置一致；有差异再补 |
| P0 | 文本 / 多模态：官方入/出价 USD/1M + 燧点入/出 | 官方价取自广场；燧点 ×7000 |
| P0 | 图片生成 / 图片识别：按张官方价/燧点价 | 燧点 ×7000；本版不要求分辨率 |
| P0 | 视频生成 / 视频识别：按秒官方价/燧点价 | 燧点 ×7000；本版不要求分辨率 |
| P0 | 语音合成：按万字；语音识别：按秒 | 燧点 ×7000 |
| P0 | 世界模型：输入按次 + 输出按秒 | 有广场价则填；缺独立字段时对应项可空 |
| P0 | 向量与检索：文本输入 + 向量输入 | 文本可按 Token 口径；向量输入缺倍率时可空 |
| P0 | 列表合表返回 | 厂商 + 类别 + 对应价格字段同条返回 |
| — | 列表范围 | 已定：按筛选条件全量展示 |
| — | 供应商列表 | 已有 |
| — | 抬头 6 常量接口 | 不做（前端写死） |
| — | 计费口径筛选项 | 新版前端不要求，本版不做 |
