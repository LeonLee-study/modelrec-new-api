深圳市模荐科技有限公司（以下简称“**模荐**”或“我们”）高度重视您的个人信息与隐私保护。我们制定本《隐私政策》（以下简称“本政策”），旨在向您说明：在您访问、注册、登录、使用模荐所提供的产品及服务时，我们如何收集、使用、存储、委托处理、共享、转移、公开披露及保护您的个人信息，以及您如何行使相关权利。

请您在使用本服务前，仔细阅读并充分理解本政策。**您使用或继续使用本服务，即表示您已充分理解并同意本政策。** 如您不同意本政策的任何内容，请停止使用本服务。

### 要点速览（详细约定以正文为准）

* **注册只需手机号或邮箱。** 我们**不收集**您的身份证件信息、人脸等生物识别信息。
* **收集范围限于服务必需。** 主要包括账号信息、调用日志、用量计费信息及您主动提交的交互数据。
* **交互数据按接入模式区分。** BYOK 模式下不在云端长期存储；平台 API 模式下存储以支持上下文与计费。
* **我们不出售您的个人信息。** 仅在委托处理、必要共享、法定情形下向第三方提供。
* **境内存储为原则。** 如因您主动选择境外模型而需出境，将依法单独告知并取得同意。
* **您可随时行使权利。** 查阅、复制、更正、删除、撤回同意、注销账号，15 个工作日内响应。

## 一、适用范围及相关定义

**1.1**本政策适用于我们通过网站（含网页端）、应用程序（可能包含不同版本、不同名称）、应用程序编程接口（API）、MCP（Model Context Protocol）协议以及随技术发展出现的其他形态向您提供产品与服务并处理您个人信息的情形。针对某些特定产品、服务或特定终端，我们可能另行制定专门的个人信息保护规则；如该等专门规则与本政策不一致，在特定产品、服务或特定终端范围内优先适用该专门规则。

**1.2**本政策所称“个人信息”，是指以电子或者其他方式记录的、与已识别或者可识别的自然人有关的各种信息，不包括匿名化处理后的信息。

**1.3**本政策所称“敏感个人信息”，是指一旦泄露或者非法使用，容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害的个人信息，包括生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等信息，以及不满十四周岁未成年人的个人信息。

**1.4**如您基于本服务向您的员工、客户、最终用户或其他第三方提供服务（包括但不限于通过自建应用将本服务接入企业微信、飞书、钉钉等平台，作为机器人提供服务），您应自行向相关人员提供适用的隐私政策。本政策不替代您与您的最终用户之间的隐私政策或个人信息处理规则。在该场景下，**您作为个人信息处理者，我们作为技术服务提供方受您的委托处理相关交互数据**。

**1.5**本政策与《模荐用户协议》共同构成您使用本服务的完整约定。二者不一致时，就个人信息保护事项以本政策为准。

**3.2**我们使用 Cookie 和同类技术的目的包括：

* 记住您的登录状态、语言、界面设置或其他偏好；
* 分析网站访问和功能使用情况，以改进产品和服务；

**3.3**我们不会将 Cookie 和同类技术用于本政策所述目的之外的任何用途。您可以通过浏览器设置管理、拒绝或删除 Cookie；但如果您禁用 Cookie，可能导致部分功能无法正常使用。

**5.2存储期限 ** 除国家法律法规另有规定外，我们仅在为实现服务目的所必需的时间内保留您的个人信息。具体而言：
